# Student Performance Dataset

**Course:** CUL-CYB 371 – Data Mining and Data Warehousing  
**Project:** Assignment Two

## Description
This project creates a fictional student dataset using Python. It contains 15 student records and the five fields required for the assignment:

1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

All student information is fictional and is provided for academic practice only.

## How to run
1. Install Python 3 if it is not already installed.
2. Save `create_dataset.py` in a folder.
3. Open a terminal or command prompt in that folder.
4. Run:

   ```bash
   python create_dataset.py
   ```

5. The program creates `student_dataset.csv` in the same folder. Open it with Excel or any spreadsheet application.

## Files
- `create_dataset.py` – Python program that creates the dataset.
- `student_dataset.csv` – Dataset generated by the program.
